# 随包建模技能

`skills/blender-modeling/` —— 一套**建模作业指导书**（入口 `SKILL.md` + `references/`）。

它回答的不是"这个工具有什么参数"，是**"什么时候该用哪个、什么算做完"**：

- 三条纪律：**改一步看一眼**（每步要有画面或数字证据）· **三态判定**（证据不足报 `unresolved`，不二选一）· **破坏性操作前置门控**
- 24 条编号配方（基本体 / 分面装甲板 / Bevel+SubSurf 光滑栈 / bmesh 编辑 / 布尔开孔 / 镜像 / 阵列 / 人形素体 / 头型 / 车辆放样 / 照片校正 / 特征线 / 参数搜索内环…）
- **六条必踩的坑**、**数值门清单**（交付前逐条过）、多 Agent 并行建模的分工范式、参考图驱动的形体还原（三视图标定 + 双证据验收）

## 为何要它

没有它，进来的 agent 看得到 35 个 `action`，却不知道什么时候该用哪个，于是自然会伸手去够万能的 `do`，然后靠目测报"完成了"。

这份指导书就是把"路标"补上。

## 工具译名表

它对时带一张**工具译名表**：上游文档写的是 `blender_rt_*`，而本 App 的工具面是 `blender` + `action=` —— 同一个内核，两套叫法。
