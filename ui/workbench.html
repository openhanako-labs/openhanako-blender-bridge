addon 地址

          
Blender 侧 addon 监听的地址。默认 127.0.0.1:9876。改完会自动重启中继。

          

            
            
          

          

            
            
          

        


        

          
投递目录

          

            产物默认归档在 App 数据目录里（谁也拿得到、不会丢）。
            如果还想把成品再拷一份到别处——比如 ComfyUI 的 input 目录、你自己的工程文件夹——
            把绝对路径填在这里。留空就不拷。
          

          
          

            
            
          

        


        

          
归档

          

            每次产出（一次多视角 / 一次 QC / 一次导出）收进一个 run 目录，带户口、可标记、可回溯。
            带基线标记的永远保留，其余只留最近 20 个。
          

          

          

            
            
          

          

        


        

          
安装指引

          
    
            
  1. 装 Blender 本体（4.x / 5.x 均可）。
    2. 
            
  2. Blender 里 Edit → Preferences → Add-ons → Install…，选 addon.py，勾选启用。
    3. 
            
  3. 3D 视图按 N，找 MCP for Blender 面板，点 Connect（默认 127.0.0.1:9876）。
    4. 
            
  4. 看顶栏那个状态点变绿就算通了；宿主侧栏「Blender 状态」里也有中继与 addon 的实时状态。
